# Learning Mentor International Academy

A multi-page static website built for **Learning Mentor International Academy**, designed around structured academic mentorship, clear visual hierarchy, and responsive layouts.https://github.com/bismac707/LEARNING-MENTOR-INTERNATIONAL-ACADEMY.git

## Brand & Visual Identity

* **Typography:** `Montserrat` for headings and `Poppins` for body text and UI elements
* **Color Palette:**
  * **Primary:** Deep Burgundy (`#8C2C3F`)
  * **Accent:** Warm Gold (`#FCB433`)
  * **Background:** Clean White (`#FFFFFF`)

## Project Structure

All pages are standalone HTML files managed inside the `LM PROJECT` workspace:

| File | Page / Purpose |
| :--- | :--- |
| `index.html` | Home landing page and academy overview |
| `about.html` | About Us, story, mission, vision, and highlights |
| `course-grid.html` | Courses and learning tracks directory |
| `gallery.html` | Campus & learning photo gallery with category filters and lightbox |
| `blog-details.html` | News, academic insights, and featured article |
| `contact.html` | Contact details, admissions inquiry form, and campus hours |
| `error.html` | Custom `404` page not found view |
| `maintenance.html` | Scheduled portal maintenance page with countdown timer |
